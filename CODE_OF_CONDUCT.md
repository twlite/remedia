# Contributor Covenant Code of Conduct

Remedia contributors are expected to create a welcoming and respectful environment for everyone,
regardless of background or identity.

Examples of behavior that contributes to this environment include being considerate, giving and
accepting constructive feedback respectfully, and focusing on what is best for the project and its
community. Harassment, personal attacks, discriminatory language, and publishing another person's
private information without permission are not acceptable.

Project maintainers are responsible for clarifying and enforcing these standards. Report conduct
that violates this code privately to the repository owner or a maintainer through GitHub. Do not
make a public issue for a private or sensitive report. Maintainers will review reports and take
action they consider appropriate to protect the community.

This policy is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
