# Crossfade protocol

The implemented public protocol is documented in the Fumadocs
[server reference](../apps/docs/content/docs/server/protocol.mdx),
[playback guide](../apps/docs/content/docs/core/playback.mdx), and
[client guide](../apps/docs/content/docs/client/overview.mdx).

Crossfade remains opt-in at both server policy and individual remote session
creation. Embedded configuration is authoritative. Ordinary sessions retain
single-source playback and compatible Opus passthrough.
