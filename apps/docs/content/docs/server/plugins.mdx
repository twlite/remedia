# Plugin host protocol

`@remedia/plugin-host` registers and executes application-defined operations. Its core API operates directly on request objects. HTTP is an optional transport for independently deployed hosts, not a requirement for local Remedia clients.

## Local request-object communication

```js
import { createPluginHost } from '@remedia/plugin-host';

const host = createPluginHost({ name: 'Local services' });
host.register({
  id: 'example.lookup',
  operations: {
    lookup: async ({ id }, { signal }) => ({ id, title: 'Example' }),
  },
});

const result = await host.handle({
  pluginId: 'example.lookup',
  operation: 'lookup',
  input: { id: '123' },
});
// { handled: true, result: { id: '123', title: 'Example' } }

await host.close();
```

The handler executes directly, preserving object identity and accepting non-JSON values. `host.execute(id, operation, input)` is an equivalent positional call. There is no HTTP listener, socket, proxy, or serialization step.

When a handler returns `createMediaSource({ open: ({ signal }) => readable })`, local consumers receive the source object and can open it directly. See the [package README](https://github.com/twlite/remedia/tree/main/packages/remedia-plugin-host) for a complete example.

## Optional HTTP host

```js
const remote = createPluginHost({
  name: 'Remote services',
  publicUrl: 'https://plugins.example.com',
  token: process.env.REMEDIA_PLUGIN_TOKEN,
});

// Standard Fetch API Request -> Response
const response = await remote.fetch(request);
```

For Express, Connect, or Node HTTP, mount `createNodeMiddleware(remote)` from `@remedia/plugin-host/node` at the origin root, before body parsers. Unmatched paths pass to the next middleware. Hono and other Fetch-compatible routers can delegate to `remote.fetch(request)`.

## Endpoints

| Method | Route | Result |
| --- | --- | --- |
| GET | `/.well-known/remedia` | Host discovery manifest |
| POST | `/remedia/v1/execute` | Execute `{ pluginId, operation, input }` |
| GET | `/remedia/v1/media/:token` | Redeem temporary encoded media stream |

The HTTP adapter calls the same in-process dispatcher. HTTP execution accepts JSON values and limits request bodies to 64 KiB. Handlers may return encoded Node/Web streams or deferred media factories. The remote transport returns short-lived, single-use media URLs instead of transferring stream objects through JSON.

Media URLs are bearer credentials; do not log them. Use transport encryption, authentication, and suitable network access controls. The current HTTP media route is non-seekable and does not support Range requests. The host does not sandbox plugin code.

## Scope

The host is independent of application-specific plugin APIs. Consumers register their own operations and implement any necessary adapters. Rust `remedia-server` plugin discovery and remote playback integration are separate work and are not yet part of this package.
