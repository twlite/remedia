# Plugin host protocol (experimental)

`@remedia/plugin-host` owns registration, dispatch, cancellation and an optional HTTP protocol. It has no dependencies on music providers, player frameworks or extractor implementations. Applications may supply their own adapters to register source, catalog, or other operations.

The package is experimental and private to the repository. It does not currently integrate with the Rust `remedia-server`.

## Local-only plugin host

```js
import { createPluginHost } from '@remedia/plugin-host';

const host = createPluginHost({ name: 'Local services' });
host.register({
  id: 'example.lookup',
  operations: {
    lookup: async ({ id }) => ({ id, title: 'Example' }),
  },
});

const response = await host.execute('example.lookup', 'lookup', { id: '123' });
// { handled: true, result: { id: '123', title: 'Example' } }
await host.close();
```

Direct calls do not open an HTTP listener or serialize arguments. They retain objects and stream instances returned by handlers.

## Optional HTTP adapter

```js
const host = createPluginHost({
  name: 'Remote services',
  publicUrl: 'https://plugins.example.com',
  token: process.env.REMEDIA_PLUGIN_TOKEN,
});

// A standard Fetch Request -> Response handler:
const response = await host.fetch(request);
```

For Express or Connect, use `createNodeMiddleware(host)` from `@remedia/plugin-host/node`; mount it at the origin root before body parsers. Unrecognized routes pass through to the next middleware. Fetch-based servers such as Hono can delegate to `host.fetch(request)`.

## Protocol endpoints

- `GET /.well-known/remedia` advertises the host name, protocol version, and registered operations.
- `POST /remedia/v1/execute` invokes a generic operation with `{ pluginId, operation, input }`. JSON requests are limited to 64 KiB. The response contains `handled` and optionally `result`.
- `GET /remedia/v1/media/:token` redeems a short-lived, one-use encoded media stream.

There is no reserved `track.stream` operation name. Any registered operation may return a Node/Web readable or `createMediaSource({ open })`. The latter defers opening the input until its media URL is redeemed. Values that are not JSON-compatible can be returned through direct execution but cannot be sent over HTTP.

One-use media URLs are bearer credentials. Do not log them or expose the host publicly without appropriate network controls and TLS. The media endpoint does not implement seeking or HTTP Range. Plugins execute with the permissions of the host process and are not sandboxed.

The `/.well-known/remedia` suffix is an experimental convention and is not registered with IANA. RFC 8615 requires registration when defining new well-known URIs; a provisional registration can be submitted when the protocol document is stable.

## Current limitations

Rust `remedia-server` does not yet discover hosts, route operations to them, authorize their media URLs, or play through this endpoint. Integration code for specific frameworks or extractor libraries belongs in those consuming projects, not in Remedia.
