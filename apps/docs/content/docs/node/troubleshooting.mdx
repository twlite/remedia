---
title: Native library troubleshooting
description: Diagnose platform addon loading failures and inspect bundled FFmpeg metadata.
---

Official addons bundle FFmpeg. For import failures, confirm Node.js 22.18 or newer,
the CPU architecture and libc variant, and installation of the matching optional
`@remedia/node-*` package. Reinstall with optional dependencies enabled. Installing
system FFmpeg or setting library search paths cannot repair a bundled addon.

```ts
import { getFFmpegRuntime } from '@remedia/node';
console.log(getFFmpegRuntime());
```

The report contains actual bundled versions, license and configuration. Include it
with platform details in bug reports. For playback errors after import succeeds,
inspect the source and [debug events](/docs/node/diagnostics).
