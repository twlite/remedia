## Building from source

Use the pinned repository toolchain and pnpm version. POSIX builds require a C
compiler, make, NASM, pkg-config, Python 3 and libclang. Run:

```sh
bash .github/scripts/build-ffmpeg-static.sh
export PKG_CONFIG_PATH="/tmp/remedia-static/install/lib/pkgconfig"
# Set LIBCLANG_PATH to the directory containing your build-time libclang library.
pnpm --filter @remedia/node build
```

The prefix defaults to `$RUNNER_TEMP/remedia-static/install`, or `/tmp/remedia-static/install`;
`FFMPEG_DIR` can choose a recipe output prefix but must be unset for Cargo builds,
so pkg-config supplies all static transitive link dependencies. The recipe uses
Secure Transport on macOS and pinned OpenSSL 3.6.0 on Linux.

Windows uses the pinned vcpkg manifest in `.github/native-deps/windows-cross`,
with a static-md triplet matching the Rust target and build-time libclang.
Windows ARM64 uses the SHA-256-verified upstream LLVM 19.1.7 ARM64 installer for
native libclang; conda-forge supplies pkg-config only on that host. The x64 host
uses the pinned Clang/libclang conda environment. See
`.github/workflows/platform.yaml` for the exact compiler environment and cross recipes.
No build tools are required to use a prebuilt package.

The generated native.js and native.d.ts files must be regenerated from Rust by
`napi build`. The regular platform addon loader is retained; no bootstrap is built. The static dependency audit rejects
media shared libraries. See [distribution](/docs/node/distribution) for licensing.

Compiled native dependencies are cached by target, compiler/toolchain versions,
pinned sources, build scripts and configuration. Cache hits still run configuration,
ABI and final binary dependency audits. CI's `ci` profile uses release optimization
without LTO for PR artifact validation; distributed releases retain measured fat LTO.
Ordinary Rust tests use the test profile.

See [licensing](/docs/licensing) and the root `SOURCE_DISTRIBUTION.md` for rebuilding
from the retained, checksum-verified corresponding-source snapshots without fetching
upstream dependency sources.
