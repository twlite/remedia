content or grant rights to access or use third-party media. Developers and operators integrating
Remedia are responsible for ensuring their use of media complies with applicable laws, intellectual
property rights, and the terms of third-party services. Remedia is provided under the MIT License
without warranty.

## Remedia and dependency notices

The [MIT license](https://github.com/twlite/remedia/blob/main/LICENSE) applies to Remedia.
Third-party dependencies retain their own terms. Distributed npm packages and server archives
include `LICENSE` and `THIRD_PARTY_NOTICES.md` plus the `THIRD_PARTY_LICENSES.txt` appendix. The
[notices](https://github.com/twlite/remedia/blob/main/THIRD_PARTY_NOTICES.md) reproduce dependency
copyright, license conditions, and disclaimers, including the bundled libopus backend.

## Native distribution and corresponding source

Original Remedia source and FFmpeg-independent packages remain MIT. Native addons
and server runtimes statically link FFmpeg configured with GPL and version3;
combined binaries are distributed under GPLv3-or-later obligations. Native npm
packages declare `SEE LICENSE IN LICENSES.md`. Archives include LICENSES.md,
COPYING.GPLv3, MIT and third-party acknowledgments.

Complete corresponding source is retrieved using the exact binary version, as
explained in `SOURCE_DISTRIBUTION.md` included with native npm packages; server archives carry retrieval directions in
`LICENSES.md`. The binary release's `source-manifest.json` names the Remedia revision,
hash-verified release source archive and target configurations, and a public,
content-addressed dependency snapshot. Snapshot assets are hosted on this same
repository's source-only GitHub releases and reused when inputs match. Both source
parts are publicly available before npm publication; no upstream clone is required.
The original v0.3.0 source archive remains unchanged.

This implements equivalent network source access under GPLv3 §6(d). Source must
remain available while the binaries are distributed. Redistributors must meet
applicable source, notice and installation-information obligations. Automated
checks do not establish legal compliance. See the
[GPLv3 text](https://www.gnu.org/licenses/gpl-3.0.html) and
[FFmpeg licensing information](https://ffmpeg.org/legal.html).

See [bundled FFmpeg](/docs/node/ffmpeg-9) for diagnostics and target limitations.
