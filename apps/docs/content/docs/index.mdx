# Remedia

Remedia is an audio engine under development. Its first working media pipeline is in `remedia-core`:
it opens local files and HTTP(S) URLs, decodes audio with native FFmpeg libraries, and yields
normalized PCM frames incrementally.

The output is interleaved 48 kHz stereo `f32` in Front Left / Front Right order. Core can encode PCM
to transport-independent Opus packets, and `remedia-discord` can send packets over an outbound voice
connection with DAVE encryption. The Discord transport has not yet been verified against a live
bot. Filters, remote RPC, and the Node.js engine binding are not implemented yet.
