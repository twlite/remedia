# Remedia documentation site

This Next.js and Fumadocs app contains the project's documentation. It is still using starter
content while Remedia is under development.

From the repository root, run:

```sh
pnpm --filter docs dev
pnpm --filter docs build
pnpm --filter docs start
```

Documentation pages are in `content/docs/`. Shared layout and source configuration are under
`src/lib/`.
