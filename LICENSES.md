Corresponding source must accompany every binary release as a downloadable archive
on that same GitHub release. It includes the Remedia revision, Cargo vendor sources,
FFmpeg and native dependency sources, patches and build recipes. Build configuration
records are included for each target. A source link or license text alone does not
replace corresponding source. Redistributors must preserve these materials and
meet the applicable GPL requirements, including installation information where required.
